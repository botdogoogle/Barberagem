# BeardMax — landing page demonstrativa

Site estático feito com HTML, CSS e JavaScript puro.

## Arquivos
- index.html
- style.css
- script.js

## Publicação no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os três arquivos para a raiz.
3. Vá em Settings → Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

Antes de usar comercialmente, substitua textos, depoimentos, imagens, composição, informações de entrega e links pelos dados reais e autorizados.
